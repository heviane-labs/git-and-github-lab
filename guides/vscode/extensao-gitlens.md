# GitLens

O **GitLens** é uma extensão extremamente popular para o **Visual Studio Code** (VS Code) que expande as capacidades nativas do Git dentro do editor.

---

## 💡 Para que serve?

1. **Autoria e Responsabilidade (Git Blame):** Mostra diretamente na linha em que você está digitando quem escreveu aquele código, em qual commit e há quanto tempo.
2. **Histórico e Navegação Fácil:** Permite navegar facilmente pelo histórico de alterações de qualquer arquivo ou linha de código sem precisar abrir o terminal ou o site do GitHub.
3. **Exploração de Repositórios:** Adiciona painéis laterais no VS Code para visualizar *commits*, *branches*, *remotes*, *stashes* e *contributors* de forma gráfica e interativa.
4. **Comparação de Commits/Branches (Diff Visual):** Facilita a visualização de diferenças de código entre duas *branches* ou revisões passadas do projeto em uma interface lado a lado.

---

## 🔄 Em resumo

Se o **Git** cuida do versionamento do código no terminal, o **GitLens** adiciona uma camada de "supervisão" visual diretamente dentro do VS Code para você entender o **quem, quando e por que** de cada linha de código no projeto.
